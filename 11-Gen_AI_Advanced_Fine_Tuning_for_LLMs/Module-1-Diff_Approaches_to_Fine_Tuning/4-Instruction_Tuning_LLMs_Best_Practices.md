# Instruction Tuning – Key Best Practices (Summary Notes)

### 1. Data Selection
- **Use diverse datasets**: Include varied instruction types and topics.
- **Balance general + domain-specific data**: Keeps model versatile and specialized.

### 2. Prompt Engineering
- **Contextual prompts**: Reflect real-world instructions and different styles.
- **Test prompt variety**: Prevents model from memorizing formats.

### 3. Response Consistency
- **Evaluate regularly**: Check for accuracy on repeated instructions.
- **Test task-specific cases**: Ensure reliability in targeted applications.

### 4. Avoid Overfitting Instruction Style
- **Vary tones & formats**: Prevents rigid response patterns.
- **Balance precision + flexibility**: Accurate but adaptable outputs.

### 5. Continuous Evaluation
- **Use instruction-following metrics**: Score how well outputs follow prompts.
- **Human review**: Catch quality issues missed by automatic metrics.
