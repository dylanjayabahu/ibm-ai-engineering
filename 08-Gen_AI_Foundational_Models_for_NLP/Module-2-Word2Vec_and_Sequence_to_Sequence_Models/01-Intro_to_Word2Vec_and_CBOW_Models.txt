CBOW Word2Vec Model 
    CBOW = continuous bag of words

    We start with randomly generated embeddings 
    
    then train a NN that maps input contexts words to the target word 
        we use context words on either side - remember we arent predicted next word just trying to find a way 
    


    the input to the NN is of shape 2*context_size 
        if context size is one, we input word_t-1 and word_t+1 to the model (model will try to find w_t)
        if context size is 2, we input words t-2,t-1 and t+1,t+2 to the model 
        we input these words by providng their index in the vocab 
        e.g. for context window of 1 [index_of_w_t-1, index_of_w_t+1] is inputted 
    the next layer is the embedding layer (lookup from embedding matrix)
        embeding matrix of of shape [vocab_size, embedding_dim]
            each row i is the embedding for word i
    then we combine context vectors (bag of words embedding)
        ^ this is the context representation
    then we have a linear hidden layer (s)
    and finally a softmax output layer 
        the dim is vocab_size, we produce a softmax over the vocab for which word should come next 
    

CBOW Model in Pytorch 

class CBOW(nn.Module):
    def __init__(self, vocab_size, embed_fim, num_class):
        super(CBOW, self).__init__()

        self.embedding = nn.EmbeddingBag(vocab_size, embed_dim, sparse=False)
            # note that here the input dim is vocab_size, 
        self.fc = nn.Linear(embed_dim, vocab_size)

    def forward(self, text, offsets);
        out = self.embedding(text, offsets)
        out = torch.relu(out)
        out = self.fc(out)
        return out
